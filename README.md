# XRPLedgerAmericas

**The community gateway for XRPL across the Americas.**

Website: [www.xrpledgeramericas.com](https://www.xrpledgeramericas.com)

## Repo structure

```
XRPLedgerAmericas/
├── index.html          # Homepage
├── css/
│   └── style.css       # Styles
├── assets/
│   ├── logo.png        # Add your logo (favicon + hero)
│   └── preview.png     # Add preview image (social/OG)
└── README.md
```

## Add your assets

Before deploying, add these files to `assets/`:

1. **logo.png** (or **logo.jpeg**) — Your XRPLedgerAmericas logo. Used as favicon and in the hero card.
2. **preview.png** — Image used when the site is shared (Open Graph / social preview).

You can copy them from wherever you saved them (e.g. your Cursor project assets folder) into this repo’s `assets/` folder.

## Deploy to Vercel

See **[DEPLOY.md](./DEPLOY.md)** for step-by-step GitHub push and Vercel deployment, including connecting **www.xrpledgeramericas.com**.

## Long-term structure (optional)

As the site grows you can add:

- `/ecosystem` — Featured projects, regional coverage
- `/builders` — Founders and devs
- `/community` — Events and spaces
- `/news` — Project updates

This repo is the starter for a regional XRPL hub.
